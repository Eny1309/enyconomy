# Enyconomy

Goldmachen in World of Warcraft (Midnight) - zwei Teile:

- **[web/](web/)**: Web-Dashboard für Flips über mehrere Realms und Deals, aus den stündlichen
  Blizzard-Auktionsdaten und den TSM-Regionsdaten. Läuft per Docker.
- **[addon/](addon/)**: WoW-Addon: legt die Sniper-Liste aus dem Dashboard in Auktionator an
  und zeigt die Preise deiner Realms im Tooltip. Ordner `addon/Enyconomy` nach `Interface/AddOns` kopieren.
